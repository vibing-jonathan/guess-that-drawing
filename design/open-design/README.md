This directory preserves the reviewed visual source of truth for the
production frontend.

- Project: `Guess That Drawing`
- Entry: `guess-that-drawing-prototype.html`
- Design system: `DESIGN.md`
- Open Design review run: `fe6f6925-e87d-471b-811c-395b0a3aa478`
- Reviewed states: 25
- Reviewed viewports: 390, 768, 1024, and 1440 px, plus 844×390 landscape

The `prototype/` directory and artifact manifest are an unchanged snapshot of
the reviewed bundle. Production React code may modularize and bind these
styles and structures to real application state, but intentional visual
changes must first be reflected in `DESIGN.md` and reviewed in Open Design.
